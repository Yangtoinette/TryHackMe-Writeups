[10] What is the BSSID for the attacker's Home WiFi?
Le BSSID (Basic Service Set Identifier) est une adresse unique utilisée pour identifier un point d’accès spécifique dans un réseau Wi-Fi. Il correspond généralement à l’adresse MAC (Media Access Control) de l’appareil qui diffuse le réseau.
Le SSID est le nom convivial du réseau visible par les utilisateurs. Dans les tweets du compte trouvé à la question précédente, nous en trouvons qui fait mention d'un DEEP PASTE. Après recherche sur internet, il semble que ce terme correspond à un site sur le deep web, qui permet de partager du texte.
En cherchant des moyons de le consulter, nous trouvons le site https://deepweblinks.net/pastebin/, qui nous indique différents liens. Nous utilisons le navigateur tor pour nous rendre sur le site.
En cherchant le hash md5 dans la partie "recherches passées", nous trouvons une note qui contient le SSID du wifi concerné. Pour faire la correspondance avec le BSSID, nous utilisons le site https://wigle.net (très utile pour les CTF OSINT).
La recherche du SSID nous donne un seul résultat qui est le flag.
